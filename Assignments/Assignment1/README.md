# Assignment 1

This folder contains the data, Python code, figures, and written responses for
Assignment 1.

## Setup

From this folder, install the required Python packages:

```bash
python3 -m pip install -r requirements.txt
```

## Run the assignment

Run each problem from this folder:

```bash
python3 problem1.py
python3 problem2.py
python3 problem3.py
python3 problem4.py
python3 problem5.py
```

Each program prints the numbers used in `Assignment1_Responses.pdf`. Problems 2
through 5 also save the required plots in the `figures` folder.

## Files

- `problem1.py`: sample moments and fitted Normal lower tail
- `problem2.py`: OLS, Normal MLE, and Student's t MLE regression
- `problem3.py`: Pearson and Spearman correlations
- `problem4.py`: conditional mean, variance, band, and coverage
- `problem5.py`: ACF, PACF, AR/MA fits, and AICc
- `Assignment1_Responses.pdf`: written answers, one problem per page

The code follows the calculation order and statistical conventions in the Week
1 and Week 2 examples, translated into simple Python.
