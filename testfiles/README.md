# Course Tests: Python Solutions

The Python program implements all 25 tests from **1.1 through 7.6**:
1.1–1.4, 2.1–2.3, 3.1–3.4, 4.1, 5.1–5.5, 6.1–6.2, and 7.1–7.6.
Tests 8 and above are not included in this Python program.

## Where is the program?

All paths below are relative to the course repository root.

- **Run the tests:** [`testfiles/python/run_tests.py`](python/run_tests.py).
  Reads each input, calls the calculation functions, saves results, and compares them with the expected outputs.
- **Calculation functions:** [`testfiles/python/risk_functions.py`](python/risk_functions.py).
  Contains the covariance, matrix repair, simulation, return, and distribution-fitting functions.
- **Required packages:** [`testfiles/python/requirements.txt`](python/requirements.txt).

The 25 tests share these two Python files. Each test produces its own output CSV.

## How to run

Open a terminal in the **course repository root**, the directory containing `testfiles`.
Install the dependencies once, then run the program:

```bash
python3 -m pip install -r testfiles/python/requirements.txt
python3 testfiles/python/run_tests.py
```

If your terminal is already inside `testfiles`, use these paths instead:

```bash
python3 -m pip install -r python/requirements.txt
python3 python/run_tests.py
```

The program prints a PASS or FAIL for every test, followed by a total.
A failed comparison produces a nonzero exit code.

## Inputs, expected outputs, and our results

- [`Tests.xlsx`](Tests.xlsx): test descriptions and the Input/Output file mapping.
- [`data/`](data/): the instructor's input and expected-output CSVs, stored together.
  For example, Test 1.1 reads `data/test1.csv` and compares against `data/testout_1.1.csv`.
  Tests 7.5 and 7.6 both read `data/test7_5.csv` and compare against
  `data/testout7_5.csv` and `data/testout7_6.csv`, respectively.
- [`python/outputs/`](python/outputs/): the 25 result CSVs generated by our Python program.
  Their names match the corresponding expected-output files.
- [`python/outputs/comparison.csv`](python/outputs/comparison.csv): each test's status,
  comparison method, and maximum absolute difference.

Rerunning the program replaces our generated outputs. It does not change the instructor's files in `data/`.
Some output names in `Tests.xlsx` differ slightly from the actual filenames.
The program uses the names present in `data/`, such as `testout6_1.csv`.

## How results are checked

Twenty tests use numerical comparison with `atol=1e-8` and `rtol=1e-6`.
Column names, dimensions, and dates must also match.

Tests 5.1–5.5 each generate 100,000 random observations. NumPy and Julia produce different
random samples, so these five tests use a statistical comparison within five standard errors,
including checks against the target covariance. Their PASS means statistical agreement,
not an identical CSV. These are our local checks, not an official grading tolerance.

For implementation details and course conventions, see [`python/README.md`](python/README.md).
